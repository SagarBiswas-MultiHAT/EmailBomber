# Security Policy

## Reporting Security Issues

We take the security and integrity of this project seriously. If you discover a potential vulnerability or issue, please do not file a public issue.

Instead, please send an email with detailed reproduction steps to:
**192402369+SagarBiswas-MultiHAT@users.noreply.github.com**

Please provide:
- A description of the issue and potential impact
- Detailed steps to reproduce
- Environment details (Operating System, Python version)

We will respond promptly and coordinate a fix before making details public.

## Ethical and Authorized Use Policy

This software is strictly intended for:
1. Authorized benchmarking of mail infrastructure owned by you or where you have explicit permission to test.
2. Development and staging environment validation (e.g., Mailpit, MailHog, Postfix testing).
3. Measuring mail server throughput, connection limits, and latency under controlled conditions.

Any unauthorized use against third-party systems without prior written consent is strictly prohibited and violates platform terms of service as well as applicable computer misuse laws.
