# Contributing to SMTP Stress Bench

Thank you for your interest in improving this project. Contributions from the community help make this utility better for everyone.

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/<your-username>/EmailBomber.git
   cd EmailBomber
   ```
3. Create a descriptive branch for your feature or bug fix:
   ```bash
   git checkout -b feature/improved-metrics
   ```

## Development Guidelines

- Ensure your code adheres to standard Python formatting (PEP 8).
- Keep core functionality compatible with the Python standard library so zero external dependencies remain mandatory.
- Add clear docstrings and comments where appropriate.
- Include unit tests or manual verification steps for any new functionality.
- Ensure all source files retain the copyright and GPL-3.0 SPDX notice.

## Submitting Pull Requests

1. Commit your changes with a clear, concise commit message.
2. Push your branch to your GitHub fork:
   ```bash
   git push origin feature/improved-metrics
   ```
3. Open a Pull Request against the `main` branch.
4. Describe the changes, motivation, and any testing performed in the PR description.

## Code of Conduct

Be respectful, constructive, and collaborative in all project interactions. We are committed to maintaining a welcoming and productive environment.
